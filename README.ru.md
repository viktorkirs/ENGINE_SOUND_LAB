# Engine Sound Lab

[English](README.md) · **Русский**

Windows-стенд для создания звуков двигателей для Iron Sector. Приложение работает локально и синтезирует звук с момента запуска до полной остановки. В комплекте девять демонстрационных двигателей и примеры WAV.

## Запуск

Для запуска из клона сначала выполните [сборку из исходников](#сборка-из-исходников). Распакуйте созданный архив `dist/Engine-Sound-Lab-Windows-x64.zip` целиком и запустите `EngineSoundLab.exe` из распакованной папки. Поддерживаются Windows 10 и 11 x64. Установщик, Qt SDK и подключение к интернету для запуска не требуются.

1. Выберите двигатель в верхнем списке и нажмите **Пуск**. Сигнал выводится на устройство воспроизведения Windows по умолчанию.
2. Меняйте **Газ** и **Нагрузку**. Для сравнения двух нагрузок на одной частоте включите **Удержание** и введите обороты. Передача меняет отражённую инерцию, нагрузку и шум редуктора. При смене двух ходовых передач модель на короткое время снижает тягу.
3. Откройте **Конструкцию** для изменения компоновки, рабочего цикла и наддува. Во вкладке **Динамика** задаются пределы оборотов, инерция, мощность, момент, потери и seed. Для газотурбинного двигателя **Конструкция** содержит параметры газогенератора и лопаток, а **Динамика** задаёт обороты выходного вала.
4. В **Микшере** выберите слой, чтобы настроить резонанс, фильтр и насыщение. **S** включает Solo для слоя, **M** отключает его. Можно включить Solo у нескольких слоёв одновременно.
5. Выберите **Испытание** и нажмите **Запустить**. Автоматическое испытание проходит запуск, набор оборотов, смену передач, высокую нагрузку, сброс газа, торможение и остановку. Обороты, газ и нагрузка на тахометре отражают текущую симуляцию.

Кнопки **Сохранить…** и **Открыть…** записывают и загружают JSON. Изменения в списке пресетов сохраняются в памяти до закрытия приложения. Для постоянного хранения сохраните пресет в файл.

Для рядной, V-образной и оппозитной модели доступны 1–24 цилиндра. Для звезды с четырёхтактным циклом используются нечётный одиночный ряд или два равных нечётных ряда. Например, для R9 порядок `1–3–5–7–9–2–4–6–8`. Четырёхтактная двухрядная звезда чередует передний и задний ряды со смещением кривошипов на 180°. В двухтактной звезде рабочие импульсы идут по окружности, один раз за оборот. Пустое поле порядка работы включает автоматическую схему. В ручном порядке перечислите все цилиндры, для звезды допустим циклический сдвиг схемы. [FAA, Powerplant Handbook](https://www.faa.gov/documentLibrary/media/Advisory_Circular/AC_65-12A.pdf)

### Неисправности

Все регуляторы находятся во вкладке **Сбои**. Их можно менять на ходу, сохранять в пресете и применять при экспорте.

| Регулятор | Что меняется в модели |
| --- | --- |
| Пропуски искры | Для бензинового двигателя задаёт вероятность пропуска на каждом рабочем такте выбранного цилиндра. При 100% остаётся слабый импульс прокачки воздуха. |
| Износ форсунки | Для дизеля меняет подачу выбранного цилиндра от цикла к циклу и добавляет слышимый запаздывающий импульс впрыска. |
| Подача топлива | Значения ниже нуля снижают давление сгорания и тягу. Значения выше нуля добавляют перебои, а у поршневых моделей — догорание в выпуске. Для турбины меняются поток и устойчивость горения. |
| Перегрузка | Добавляет сопротивление сверх обычного регулятора нагрузки и усиливает низкочастотные вибрации. После включения удержания оборотов меняется тембр на выбранных RPM. |
| Люфт механики | Усиливает клапанные удары и модулированный дребезг передачи. Для турбины действует на редуктор. |

Для сравнения можно открыть оба звука `examples/v8_single/steady.wav` и `examples/v8-misfire_single/steady.wav`, созданные при 1900 об/мин и 58% нагрузки. Пресет с перебоями лежит рядом со своим WAV.

## Экспорт для игры

**Экспорт WAV** открывает три режима.

- **Один звук** подставляет текущие RPM, газ и нагрузку со стенда. Можно уточнить значения и выбрать цикл или фрагмент с затуханием на краях.
- **RPM Sound Pack** создаёт пять циклов (`idle`, `low_rpm`, `medium_rpm`, `high_rpm`, `maximum_rpm`) и четыре перехода (`start`, `acceleration`, `deceleration`, `shutdown`).
- **Сетка RPM × нагрузка** создаёт циклы по равномерно расставленным точкам. Задайте диапазон, до 16 точек по оборотам, до 10 по нагрузке и длительность каждого цикла. При одной точке используется нижняя граница оси.

Во всех режимах доступны 44,1/48 кГц, PCM 16/24 бит, моно/стерео и пиковая нормализация до −1 дБFS. Пакет или сетка получают общий коэффициент усиления, чтобы сохранить относительные уровни. Каждый экспорт создаёт отдельную папку с WAV, `preset.json` и `manifest.json`. Прежние экспорты остаются доступны. Рендер выполняется в фоновом потоке, его можно отменить из нижней панели.

`manifest.json` содержит имя двигателя, seed, параметры PCM, имя каждого файла, обороты, нагрузку, газ, фактические начальные и конечные обороты и границы цикла. Газ и нагрузка записываются от 0 до 1. Для цикла `loop.startFrame` включается, а `loop.endFrameExclusive` указывает на кадр сразу после конца. У переходов `loop` равен `null`. В самих WAV для циклов записан стандартный блок `smpl` с включённым последним кадром. Поршневой рендер подбирает длину близко к целому числу рабочих циклов, а турбинный точку стыка выбирает по корреляции обоих каналов. Получившаяся длительность указана в манифесте вместе с заданной.

В Godot 4 выберите WAV в панели **Import** и оставьте **Edit → Loop Mode → Detect from WAV**. Сеткой можно управлять через несколько `AudioStreamPlayer3D`, интерполируя уровни между соседними точками RPM и нагрузки из JSON. Для проверки стыков оставьте обрезку тишины и конвертацию частоты импорта выключенными. [Импорт аудио Godot](https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_audio_samples.html)

## Сборка из исходников

На Windows установите Qt 6 для MinGW x64, соответствующий компилятор MinGW-w64 и CMake 3.24 или новее. Включите Ninja и CMake в `PATH`. Проверенная связка — Qt 6.11.1, MinGW 13.1 и C++20.

```powershell
pwsh -File .\Build-Windows.ps1
```

Скрипт собирает Release, запускает CTest и создаёт переносимую сборку с Qt DLL. Для собственного расположения SDK передайте `-QtRoot`, `-MinGWRoot`, `-NinjaDirectory`. Параметр `-SkipPackage` оставляет сборку и проверки в `build`.

Для перегенерации примеров передайте папку ожидающей командой Windows PowerShell или PowerShell 7.

```powershell
$exe = Join-Path (Get-Location) 'dist\Engine Sound Lab\EngineSoundLab.exe'
$output = Join-Path (Get-Location) 'examples'
$process = Start-Process -FilePath $exe -ArgumentList '--export-demo', ('"' + $output + '"') -WindowStyle Hidden -PassThru -Wait
if ($process.ExitCode -ne 0) { throw 'Не удалось создать демонстрационные WAV.' }
```

Ядро можно собрать без Qt, передав `-DESL_BUILD_APP=OFF` в CMake. `src/core` содержит геометрию и порядок цилиндров, контроллер динамики, DSP, микшер и рендер. `src/app` содержит Qt Widgets, JSON, WAV и отдельный поток вывода WinMM. Генерация идёт с удвоенной частотой, затем сигнал проходит фильтр перед понижением частоты. Поршневому синтезу служат формы давления, фазы газообмена, задержки и отражения акустических трактов. В турбинной модели газогенератор и свободная силовая турбина вращаются независимо.

## Проверка

Автоматические проверки охватывают рабочие фазы цилиндров, нагрузку при удержании RPM, инерцию, независимость валов, слои, пропуски искры, изношенную форсунку, перегрузку и побитовое повторение экспорта. Тесты файлов проверяют три режима, все комбинации PCM и частоты, границы циклов, затухание и метаданные. Импорт PCM 16 и 24 бит, циклов и переходных файлов проверен в Godot 4.7.2.

Спектры Leopard 2, Abrams и бензинового V8 сравнивались с открытыми полевыми записями. Тембр зависит от микрофона, акустики и режима реальной машины. Источники указаны в [THIRD-PARTY.md](THIRD-PARTY.md).
